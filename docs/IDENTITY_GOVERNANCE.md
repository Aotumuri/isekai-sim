# 集団別の統治と政治的安定

政府がどの集団を公認し、どの集団に制度上の保護や制限を設けたかを観察できる。国の政治画面に公認集団・待遇・最近の決定理由・正統性・不満と自治要求を表示する。地図では Space キーを押して地区にカーソルを合わせると、蓄積した不満と主な要因を確認できる。

## 政府と人口

地区人口は、祖先・文化・宗教それぞれの人数を独立した周辺分布として保持する。政府は各次元について一つの公認集団を持つ。公認には表示名や配列番号と独立した集団IDを使う。初期の公認集団は、祖先と文化では首都、宗教では全国集計を基に決める。既存の郷土綱領や国教に集団指定がある場合は、その指定を引き継ぐ。国教と郷土綱領は同居できる。従来の国号と領土請求に使う綱領は初期に選択し、対応する集団の公認変更を反映する。

人口構成や首都が変わっても公認は継続する。少数派を公認した状態でも、他の集団が通常どおり制度に参加できれば不満は生じない。保護や制限を含む待遇は、公認とは別の政府の判断として保持する。集団横断の人数や、各集団の忠誠度は推定しない。

| 待遇 | 制度上の効果 |
| --- | --- |
| 容認 | 通常の制度参加。個別指定のない集団の既定値 |
| 保護 | 制度上の保障。不満を緩和し、包括的な旧来の宗教制限と強制移動の対象から除外 |
| 自治 | 文化・宗教の機関を地域に委ねる。保護と同様の保障 |
| 同化 | 文化または宗教の変更を促し、制度上の圧力が発生 |
| 制限 | 不均等な権利や制度参加から不満が発生 |

強制移動の既存命令は綱領と対象資格を引き続き使う。一般の権利制限から強制移動命令が直接発生する仕組みは設けていない。旧来の宗教制限は国教以外の宗教に及び、個別の保護・自治が優先する。従来の命令に伴う短期の国内反発と外交反応は、地区に蓄積する制度的不満に加えて発生する。

## 地域の不満と自治

100日ごとに統治下の各地区を評価する。同化には0.62、制限には1、保護・容認・自治には0を適用する。各次元内で待遇を受ける人口比にその値を掛け、三次元の合計を3で割る。同じ住民が受ける複数の待遇について、人口の共通部分は求めない。

制限の強まりや自治の撤回は短期の反発を生む。食糧不足は制度的な不満を増幅する。食糧不足自体は従来どおり食糧・国内不安の系統でも処理する。自治で不満の目標値を30%下げ、個別保護と自治は対象人口に応じてさらに緩和する。短期の不満は100日ごとに目標値へ35%近づき、長期の記憶は短期の値へ4%近づく。両者を65対35で合成する。改革や政権交代後も長期の記憶は残り、継続した救済とともに減衰する。他国の占領中は当該政府による制度適用を一時停止する。領土移転後は新しい政府の待遇を適用し、地区に蓄積した記憶を引き継ぐ。

人口加重の全国不満を正統性と国内不安に反映する。正統性は100から全国不満の75倍を引いた値。多様性は観察用の指標として保持する。大きな全国不満は既存の支持率審査で政権に不利に働く。持続する地区の排除は、対象集団による保護や現地管理の要求につながる。属国では地区の不満が独立圧にも作用する。

遠隔地の不満は、革命が成立しうる場合の発生地選定に使う。革命には累積した国内圧力に加え、従来の飢饉、または戦時の長期低支持と危機条件を要する。国外の再統一運動は、従来の集住・隣接・外交条件を満たす候補のなかで、対象の祖先集団が受けた待遇を根拠に優先順位や外交摩擦を強める。

## 自律審査と属国

初回審査は国ごとに時期をずらす。通常の審査間隔は400日、決定後の間隔は800日。政府はその時点の支持率・イデオロギー・体制・協調性・食糧不足・正統性・戦争を使って、公認や個別待遇のうち一件だけを選ぶ。国勢調査で公認を再選定する処理は行わない。協調的な政府は保護を選びやすく、結束主義の政府は行政文化の普及を選択しうる。支持の厚い王政の一部では、祖先・宗教に関する制度上の制限や、国教への改宗を促す措置も候補となる。不満が高まると保護・容認への改革が有力になる。閾値に届かなければ現状が続く。各判断はイベントに記録し、国ごとに直近6件を保持する。

属国は宗主国と独立した公認・待遇を持つ。イデオロギーが同じで信頼や依存が強ければ、宗主国の公認集団に合わせる選択が有力になる。現地の代表性を失う費用、自治圧、正統性の低下はその選択を抑える。宗主国の公認を採用しただけでは人口や他集団の権利は変わらない。属国が国内自治を取り決めると、宗主国の公認に合わせる制度上の働きかけは止まる。自律的な平和統合は双方の政府が審議し、文化の一致、信頼、平和、自治圧、領域支配などを評価する。

## 人口変化と計算量

文化・宗教への同化政策がある地区では、対象の文化人口の1.8%、宗教人口の0.5%を100日ごとに同じ次元内の公認集団へ移す。地区人口および各次元の合計は保存し、祖先への変換は扱わない。地域自治は制度による同化を停止する。通常の移住・港湾交流・食糧・領土移転は従来の処理を使う。

地区の所有者索引を使い、人口集計・制度の適用・不満の集計を一巡で行う。初期化時のみ、未初期化国向けに国教選定用の集計を行う。政策の参照表は各周期に国ごとに一度作り、地区間で共有する。地区の記憶は不満が残る間だけ保持し、国の審査は各次元の集団に対する単独の変更候補を比較する。100日周期の政治処理を時間計測できる。

地区の記憶は二つの時間尺度と最大の要因を保持する簡易モデルで、集団別・政権別の記憶台帳には対応していない。全国行政の自治と地区ごとの合意はそれぞれ別の制度として適用する。地区の交渉手続きは[地域自治交渉と属国の政治判断](REGIONAL_AUTONOMY_AND_SUBJECT_POLITICS.md)を参照。食糧不足は代理指標で、戦災と強制移動の長期的影響を個別に記録する仕組みは今後の課題。保存世界の読込機構が導入される際は集団IDと旧来の綱領の移行処理が必要になる。
