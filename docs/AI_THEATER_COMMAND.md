# 主戦域の指揮官による作戦発進判断

## 事前に定めた判定条件

キャンペーン有効の自動国家に、優先交戦相手を担当する指揮官を一人置く。選好は世界・国家・任官番号から決定し、通常の作戦が発進可能になった場面にだけ影響させる。慎重な指揮官は準備率が既存条件から10ポイント未満の余裕しかないとき、一度だけ追加の集結を待つ。時間に余裕があり、緊急時限や特殊目的のない作戦に限る。後任の就任は作戦の目標・担当部隊・期限を更新せず、一度発した待機を繰り返さない。指揮官の選好だけを交換した同条件の実行で発進と待機を分け、待機翌回に通常の発進条件で進めることと、政権交代・手動国・無効設定を確認する。

## 結果

主戦域に対する通常の発進判定で75秒を超える戦略上の余裕と1 slow tick以上の準備猶予がある場合に適用。任官と交代は該当する次の発進判断で行う。作戦に保存した判断は当時の指揮官・準備率・希望準備率・評価tickを含み、進行中の作戦の後任には引き継ぎ済みの判断として扱われる。大攻勢・救援・補給遮断・包囲の形成と縮小には既存の発進規則を適用する。

準備率65%の同条件で、60%で十分とする指揮官は発進、70%を求める指揮官は一回待機した。政権変更後の次回評価で同じ任務・部隊のまま発進し、新規判断では後任が任官した。手動国・無効時の発進も確認。回帰739件、型検査、build、quick benchmark が成功。自然再生での発生頻度・戦争結果・長期CPU差を評価するまでは試作。待機以外の命令権・忠誠・軍内支持は今後の対象。
