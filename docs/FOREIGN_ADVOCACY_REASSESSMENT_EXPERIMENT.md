# 地域要求に対する外国支援の再審査実験

本番は要求発生後の初回審査を維持する。再審査で支援が成立する条件は制御ケースで再現できた。固定シードでは追加支援が生じたものの、同じ時点の政府判断から外国支援の効果だけを取り除く比較で、提示条件の変化は確認できなかった。再審査は診断で比較できるようにした。

## 初回審査と要求の寿命

[前回の実験](FOREIGN_ADVOCACY_SCHEDULING_EXPERIMENT.md)では、政府判断を記録した99件中、600日周期は17件、要求発生時の予約と100日周期は各82件で初回判断前に審査できた。予約方式は審査遅延の中央値を100日から10日に縮めた。前回のA/B/Cは初回審査の比較である。今回の3方式は全て予約方式で初回審査を行う。

- 1日ごとの更新が10日目に達すると低速更新を実行する。低速更新では宗属、亡命、領土請求の更新に続いて外交運動と外国支援が走る。その後で国内政治、外交関係、派閥、危機、領土移動などが更新され、後段の領土統治で要求を作成・審査する。初回審査の予約は地区ID、作成時の所有国、交渉オブジェクトに与えた世代識別子、作成時刻を持つ。所有国と世代が一致する生存案件だけを次の低速更新で処理する。
- 地域住民の待遇と不満から要求が発生し、通常は100日後に政府が拒否、部分保護、全面譲歩を判断する。戦時の欠乏で一度200日延期し得る。政府が提示すると100日後に地域側が受諾または拒否する。要求が政策変更で満たされた場合や支持基盤が失われた場合は取り下げる。成立、拒否、取下げ、所有権移転で生存案件の追跡を終える。同じ地区での新規要求は別世代になる。
- 外交影響力の初期値は30。外交関係更新は100日ごとに3を補給する。上限は100。同じ周期の条約、援助、外交運動などの支出で相殺され得る。新規支援は残高42で審査に通り、提示時に22を支出する。支援成立後の後援国クールダウンは2,000日、運動が拒んだ後の後援国別クールダウンは3,000日。再開した同じ地区・所有国の交渉に拒否記録が引き継がれる。同時に保持できる支援は2件。
- 接触を作るのは国境、有効な通商・同盟条約、同派閥への所属。不可侵条約単独や宗属関係単独では接触を作らない。直接の宗属関係と二国間の戦争・危機は審査を止める。間接的には宗主国との条約が関心を下げる。接触探索は対象国集合に絞り、既存の国境索引、条約、派閥の所属を使う。
- 外国政府の関心は、優遇集団との一致、文化の統治上の結びつき、地域の人口比率と領土請求、外交関係の対立、政府の理念・性格、当事国や宗主国との条約で決まる。政権の理念変更には性格の更新が伴い得る。対象国の正統性、地域の不満・不信、すでに提示された国内譲歩は主に運動側の受諾に響く。支持の強さと反発の程度が政府の譲歩判断に加わる。
- 既存の支援は100日周期で減衰し、1,600日ごとの更新では当事国が存続し、関心と影響力を保てるかを確認する。所有者の違う案件や終了した案件は支援・容量の対象から外れる。現行の更新判定には戦争、危機、接触喪失による独立の終了条件がない。この実験では既存支援の更新規則を変更していない。

## 実験方法

| 方式 | 初回の後 |
| --- | --- |
| A 初回のみ | 10日ごとの読み取り診断で機会を記録する。本番と同じ初回の行動だけを実行する。 |
| B 条件変化 | 10日ごとに生存中の審査済み案件を監視する。スポンサー側の全条件が初めて、または再び成立した場合と、適格なスポンサーへの運動の判断が受諾に転じた場合だけ再審査する。 |
| C 100日間隔 | 初回から100日後、以後100日間隔で生存案件を確認する。Bと同じ判定で再審査する。 |

Bは閾値を横切った時点で審査する方式の実験。通知の取りこぼしと実装コストを混同しないよう、10日ごとに状態を読み取って閾値の横断を検出した。したがってBの探索CPUは、この監視で計測した費用である。小さな数値の変動や、別の拒否条件が残る変化では再審査に進まない。B、Cとも生存案件の対象国だけで接触表を一括作成し、他国の組を総当たりしない。

診断は実際の審査と同じ関心、提示強度、反発、受諾の式を参照する。外交関係、影響力、国民性、理念、領土記憶は未初期化の時も既定値を読み取る。地理索引の遅延構築は診断側のキャッシュに閉じる。交渉の追跡は世代番号、候補ID、初回と直近の評価、解除条件だけを保持し、世界の複製や乱数の追加消費を避ける。終了後の影響力追跡は500日で打ち切る。Cの100日標本では、終了前の回復を見落とせるため、回復時期の集計にはAを使った。

候補の分類は接触なし、当事国が失効、戦争・危機、直接宗属、容量、後援国クールダウン、運動の過去の拒否、関心不足、影響力不足、支援中、国内案を優先、その他の運動拒否を記録する。初回の主要理由は審査順で最初に該当するものとし、同時に該当する理由と、仮に提示された場合の運動側の判断も記録する。新たな接触の発見時は国境、条約、派閥の該当経路を集計する。

実行時は現在の要求オブジェクト、所有者、接触、当事国、戦争・危機、関心、影響力、容量、クールダウン、既存支援を確認する。地区ID、受諾見込み、受諾の余裕、後援国IDという既存の順序で候補を扱う。同周期に先の案件で支出した場合、提示時に既存の支出額22を払えるかを再確認する。残高42は候補審査時の条件である。支援の更新・減衰、支出、外交関係の変化、政府判断は既存処理を使う。

## 制御ケース

- 影響力39で初回を見送り、外交関係更新で42に達した翌回にBで受諾。第310低速更新の政府判断は、支援の効果を外すと部分保護、支援込みでは要求どおりの自治だった。Aでは部分保護を提示した。Cの最初の再審査は第311低速更新であり、先に出た政府の提示はそのまま残った。
- 影響力が不足し続けるケース、終了後に回復するケース、回復と後援国クールダウンが重なるケースでは、該当期間の支出はゼロ。関係がわずかに変動しても閾値未満では再提案しない。集団との結びつきが変わり関心の閾値を超えたケースでは支援が成立した。
- 通商条約、派閥加入、国境移動で候補を発見した。期限前にBで見つけた通商相手がCの審査時には失効していたことと、新しい同盟が関心不足を補わないことを再現した。戦争・危機および直接の宗属関係の解消も個別に確認した。
- 十分な国内案を提示済みの運動は、新たに資金を確保した後援国を拒否した。拒否のクールダウン中に外交関係が変わっても追加支出はなかった。支援成立済み、交渉成立済み、政府消滅、他国への所有権移転、同じ地区での別要求への差し替えは旧候補からの支出を止めた。
- 同一周期で複数地区が同じ後援国を求める場合の容量・クールダウン・残高と、複数の後援国が同じ運動を支援しようとする場合の優先順を確認した。監視だけを追加した実行の世界と乱数の状態は同じだった。

### 外交と国内判断への影響

Bの再審査で5件を提示し、3件が受諾、2件が拒否された。提示は受諾の有無にかかわらず、該当する二国間関係の緊張と信頼を変えた。初回を含む全提示はA・Cの13件からBの15件、全受諾は8件から9件、全拒否は5件から6件に増えた。Cの追加提示はゼロだった。小782と261国781では、先行の受諾後に後続案件の初回審査でクールダウンが記録され、Aにあった各1件の提案が消えた。221国780では先行の拒否後、後続の初回審査の影響力不足が1候補増え、Aにあった1件の提案が消えた。

再審査で支援が成立した小782の `meso-51`、中788の `meso-8`、261国781の `meso-1566` は、支援込みでも、同じ状態から支援効果だけを除いても、政府は拒否した。比較は判断の式を読み取るだけで、世界に別の決定を適用していない。AとBでは、提案があった4シードすべてで、観測終了までの開戦、終戦、領土所有権変更、革命、地域合意、地域交渉の拒否の各総数が一致した。世界署名には影響力や関係、支援の履歴による違いが残った。この比較から個々の後続イベントの因果や観測期間後の影響は確定できない。
