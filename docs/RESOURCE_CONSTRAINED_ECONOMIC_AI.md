# 資源制約下の国家経済AI

## 調査目的と比較条件

資源不足を観察できる自律世界を対象に、燃料の物理的な不足、計上の意味、支払結果と稼働状態の整合、国の意思決定を検証した。起点は既存ローカルの `main`、`c3fd719`。既存の政治・外交・属国政策の挙動を継続し、外国政治支援の本番審査は要求発生から10日後の初回審査を維持した。再審査で支援成立が増えた既報でも、自然発生の政府判断を変えた例はなかった。[外国支援の再審査実験](FOREIGN_ADVOCACY_REASSESSMENT_EXPERIMENT.md)

- **A** は起点の本番挙動。燃料の詳細比較には観測フックだけを入れた状態でも同じシードを走らせた。
- **B** は稼働燃料の実支払、無給油の輸送船が支える海上補給の再評価、国家統合時の援助返却を修正した状態。
- **C** はBに、未使用の科学枠を材料の足りる有効な研究計画へ回す処理を加えた採用版。

1 fast tick は1日。1 slow tick は10日、1年は365日。量の平均は、世界の累積量を経過した10日周期数で割った。国別の不足日数は、その国に未充足の稼働需要があった10日周期の長さ。採取点は生産終了直後と10日周期終了時。経過日数、国数、計測の母数を分けた。 [シミュレーション時間](SIMULATION_TIME.md)

## 在庫と精算順

金額・物量の正本は `nation.resources`、`nation.food.stock`、`nation.treasury.balance` と輸送中の貨物・代金。後二者を含む貿易は `TradeDeal` の双方のエスクローに記録し、物資援助は `ArmsAidShipment` の輸送中の兵器を含む。国の使用可能残高にエスクローは含めず、世界集計には含める。支払い前に保護する試作用燃料は国内在庫の一部分。備蓄目標、輸出下限、輸送予定、賠償予定も、現在庫への加算や消費の記録を伴わない。

| 順序 | 処理と会計上の意味 |
| --- | --- |
| 日次と10日周期の冒頭 | 領土、政権、属国、割譲・講和、影響力を更新。国庫の課税は100日ごと。軍事助成は費用を支払い、動員・地理的補給の評価を先に行う。 |
| 国内産出と運営 | 領有・占領・復興状況に応じて鉱山が鋼材、燃料、銅、ゴム、タングステンを産出。工場は鋼材を支出し兵器を産出。部隊の10日分の燃料を配分し、徴募があれば兵器・兵員・該当する戦略資材を支出。 |
| 復興と移転 | 工業復興、捕虜処理、賠償、宗主国からの産業支援、復員の順。賠償と産業支援は引き渡し時に双方の残高へ反映する。 |
| 試作と建設 | 有効なプログラムの科学進捗分だけ鋼材・兵器と装備別の試作材を支出。研究の追加助成は利用されたときに国庫から支出。改装、公共事業、沿岸投資を続ける。 |
| 調達と輸送 | 食料の取引判断、輸送中の取引の到着・返却、工業調達、人口移動、食料供給。燃料等の購入は在庫と現金をエスクローから移し、海運燃料だけを支出する。武器援助・技術交流はこの後。 |
| 国家成立と継承 | 分離時は親国から資源と国庫・食料を按分。平和統合では取引・武器援助のエスクローを先に返却し、旧政府の在庫・現金・食料を相続する。属国の産業支援・食料徴収はそれぞれの制度の条件で決済する。 |

期末在庫は、期首在庫に産出と実際の受取を加え、搬出、実消費、明示された損失を引く。輸送中の物量と現金を含めると、世界集計では当事者間の移転が相殺される。燃料積荷は移転、運賃相当の燃料は実消費。食料では収穫を産出、配給を消費、貯蔵上限を超えた分を損失として扱う。現金では税収と初期口座への付与が流入、研究・軍事・救済・建設・援助の承認済み費用が流出。燃料の世界集計は毎10日、全政府とエスクローを含めて照合した。鋼材・兵器・銅・ゴム・タングステンは国内生産の出力・材料投入・徴募費を精算直後に照合し、後続の移転は制御テストで検証した。

`resourceFlow` は直近の変化を表示するための集計。生産後の `income` と `usage` には貿易・援助の入出庫や試作も加わる。国内産出は `industry.output`、稼働要求と実支払は `industry.fuelDemand`、`industry.fuelConsumed` を読む。計画無効時も使用欄は実支払を記録し、稼働要求を別に保持する。旧実装の計画無効時は、在庫から不足分を引かなかった一方、使用欄には要求全量を載せていた。

## 確認した欠陥と修正

1. **燃料が正なら対象部隊はすべて稼働。** Aの国別支出は `min(使用可能在庫, 国の需要)`。その結果、在庫が4、支払単価が3、対象が3部隊なら、引落4に対して稼働状態は全3部隊分だった。B以降は決定的な部隊配列順に、払える部隊に10日分を全額割り当てる。同じ例で1部隊に3を払い、残り1を繰り越す。低額の要求が後にあれば残高の範囲で支払える。旧来の試作保護枠を先に差し引き、新規部隊は既存部隊の後で支払対象になる。搭載中・人員ゼロ・領土のない政府の部隊は対象外。同一周期の再実行は産出と支出を重複させない。
2. **輸送船の無給油と海上補給。** 補給割り当ては輸送船の存在を見ており、移動不能な船も航路を支えた。輸送船の給油状態が変わり既存の海上リンクがある場合、徴募後に補給を再評価する。制御地図で輸送船1隻の無給油で離島の補給が切れ、次の周期に2を支払うと同じ船で戻った。部隊の燃料と領土の接続判定は、それぞれの条件で評価する。
3. **統合後の援助返却先。** 旧政府の兵器12が援助輸送中に統合されると、その後の返却で兵器が旧政府に残った。取引エスクローと同様に、援助を先に各送り手へ返す。旧政府が送り手ならその在庫を相続し、第三国が送り手なら第三国が受け取る。発送済みの運航燃料は支出のまま。
4. **研究の材料不足で科学枠が遊休。** A/Bでは、1つの装備系統で材料不足になると、その持分を他に回さなかった。制御ケースでは戦車と歩兵の優先比4対1、燃料ゼロ、銅・鋼材・兵器あり。Cでは歩兵に5倍の科学を配分し、戦車は停止したまま。銅も留保下限に達した対照では歩兵も停止する。Cはまず各系統に従来の持分を割り当て、残枠を優先度順に有効な系統へ1巡だけ再配分する。材料費・国庫費・停止指定を守り、試作材の元の要求は調達の判断材料に残す。手動政権と経済計画無効時は元の持分のみ。

世界全体の不足は実在した。既報の中規模シード `822748319780` をAで10,000日再実行した結果、10日あたり国全体の産出235.74、稼働要求922.31、実消費228.19、未充足694.12。以前の丸め値と同じ規模だった。研究・輸送・建設は別の用途であり、稼働需要を二重に数えた結果ではない。産出が需要に届かない国に加え、産地・余剰・市場への接続が国ごとに異なる。給油判定を合わせてもその地理的・生産上の制約は残る。

## 国家判断と調達の評価

兵器の生産は工場枠、鋼材、研究用の保護量、兵器在庫と補充支出の平滑値、国の政策、戦時かどうかで決まる。平時の戦車追加では国内産出と稼働需要、試作の保護を除く在庫の50日分を照合する。戦時・動員時の編成優先は既存のまま。自動予算は100日ごとに税率と助成を決め、人口に基づく直近税収、国庫、危機、交戦状態を参照する。資金が十分でも現地の燃料、港、条約、相手国余剰の代りにはならない。国家性格は防衛・備蓄、研究配分、資金留保と価格に反映される。

調達は50日ごとに、継続費と試作要求を控除した産出、現在庫、入荷中の同品目、国庫留保、戦況を照合する。売り手には自国の備蓄目標を課す。外交関係表を一巡し、候補は品目当たり3国、買い手の経路確認は最大6件。条約・禁輸・交戦・経路を検証し、経路不成立は150日待って再審査する。現金を持つ買い手に燃料がなくても、売り手が自国の備蓄と輸送分を賄えば航送できる。到着は最短30日で、一度の燃料不足を即日埋める仕組みではない。既存の制御ケースで、実輸入、十分な現金を持つ買い手の航路不成立、売り手の余剰不足、禁輸返却、輸送後の研究再開、220の候補中最大3経路の確認を照合した。単一政府の制御ケースでは25周期の不足中の発注試行は0。

既存の評価は産出の回復可能性と直近の継続費を見る。何周期続いているか、外部供給の信頼度、保有国や出口港の偏り、国庫と工業の健康度を一つの指標では区別していない。今回は産出倍率・需要倍率・備蓄倍率・輸送上限を据え置いた。新しい産出源、代替資材、全体予測器を導入する根拠は得られていない。

### 国ごとの差と自然統合

中規模Cでは、3,650日の `nation-5` は開幕から稼働要求5,448を全額払い、国庫6,048と燃料3,930を持っていた。同時点の `nation-7` は稼働要求29,770に対して支払10,667、在庫2.96、最長不足1,550日だった。10,000日の `nation-5` は国庫13,114まで増えたが、燃料在庫3.78、累積稼働要求63,328、実支払28,704となった。産出33,000の範囲では継続費の増加を吸収できない。期末の `nation-7` は最長7,900日不足し、国庫2,616を持つ。この2国だけでも国庫・産地・支出の違いが見える。

小規模 `822748319782` のCでは、10,000日に2国、20,000日に1国へ自然に集約した。工業調達の到着は10,000日の11件から50,000日まで増えず、燃料輸入は全期間ゼロ。生き残った `nation-5` の在庫は10,000／20,000／50,000日に燃料2.92／2.17／2.11、国庫1,373／4,715／15,065、保有研究0／19／63。50,000日の最高レベルは歩兵6、戦車4、戦闘艦3、輸送船3。世界在庫3,445には過去の政府に残った在庫が含まれる。これは存続政府が使用できる在庫2.11と別に読む。試作の保護と既存在庫で研究は進む一方、長期の稼働不足は続いた。単一政府になったこと自体で産出や外部供給が増える仕組みはない。

研究再配分は10,000日の中規模Cで1,556科学、小規模50,000日でシード順に5,195／5,581／181／6,515科学を使用した。これは二巡目に成立した研究投入の直接測定。保有研究数はBより増えた例と減った例がある。戦争・支配・政府の保有計画が分岐するため、期末の研究数の差をそのまま再配分の効果に換算できない。221国と664国では再配分が682、680科学あったが、観測期間に完了研究は0件。664国も生産・調達と研究費の処理が稼働した序盤の測定で、長期大規模戦争の負荷は未検証。

## 保存、性能、決定性

- A/B/Cの比較で、世界燃料の10日ごとの保存残差が絶対値 `1e-7` を超えた周期は0。中規模 `822748319788` の最大はA `6.53e-11`、B `4.78e-11`、C `4.19e-11`。鋼材・燃料・兵器・銅・ゴム・タングステンの国内生産精算も `1e-8` を超える観測は0。国家統合と貿易・援助エスクローは制御ケースで照合した。研究以降の全品目を一括した世界通期の照合は、燃料と追加計測した食料・国庫が対象。
- 追加計測のCでは、中規模3,650日と小規模 `822748319782` の50,000日で食料・国庫の世界保存残差が `1e-7` を超えた周期はともに0。前者は食料の最大残差 `1.82e-11`、現金 `5.06e-12`。税収12,516.79、承認済み費用9.00、食料の収穫85,905.69、実配給41,958.00、貯蔵超過34,871.62だった。この追加内訳はA/Bでは未計測。

## 残る課題

- **分類A・正確性**。10日精算時の支払いと稼働の不一致、計画無効時の誤計上、無給油輸送船の海上補給、統合時の援助返却を修正した。初回精算前の初期部隊と、整備・輸入が同一周期内で変わる場合の稼働は既定の10日境界で扱う。輸送以外の海軍計画や戦術は今回の検証範囲外。
- **分類B・構造**。未使用の科学枠を再配分した。次は、国別に継続費と産出、発注前の候補不足理由、実際の到着量、不可逆な継続契約を同時観測する。特に燃料を持つ政府の余剰が離れた買い手へ届かない場合と、輸入可能でも国内の慢性的な赤字が大きい場合を分ける。その結果で継続的な備蓄や既存の裁量支出の判断を検討する。
- **分類C・平衡**。産出倍率、部隊維持率、備蓄倍率、試作費を変えるには、同じ経済条件の対照で需要・産出・地域差それぞれの影響を分ける必要がある。全量払えない要求に端数を割り当てる方式、在庫の多寡から全対象を稼働させる方式は、支払と稼働の対応が弱いため採用しなかった。既存順序では先頭側が継続的に支払われやすく、順序を変更する公平性の比較は別実験とする。
- **分類D・機能**。資源代替、インフラ投資による採掘能力の成長、長期の地域特化、民生部門、自然人口増加は追加していない。
