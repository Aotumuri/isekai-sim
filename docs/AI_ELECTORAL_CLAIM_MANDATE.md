# 選挙前の連立支持と領土要求

## 事前に定めた判定条件

キャンペーン有効の民主政で、選挙までが既存の支持再評価間隔以内、かつ連立全体の世論支持が過半数を割っている場合に、AIの領土最後通牒に追加の動機を求める。得点閾値の加算は50%までの支持不足の半分とする。既存の軍事・外交上の条件を使い、選挙を控えていない政権、支持のある連立、君主政、領土以外の要求、手動判断には追加条件を適用しない。自動要求の候補と状況を固定し、政権支持だけを替えた対照で見送りと最後通牒が分かれ、診断に当時の支持・選挙時期・閾値が残ることを確認する。

## 結果

同じ請求・軍事状況・自動要求得点50で、選挙まで10 tickの連立支持20%は閾値60となり見送った。支持60%、選挙まで45 tick、君主政はいずれも通常の閾値45で最後通牒を発した。弱い連立でも明示の手動要求は成功した。議席・支持・選挙の更新規則を再利用し、追加する状態は既存の見送り記録に保存する判断時点の情報のみ。回帰738件、型検査、build、quick benchmark が成功。自然な選挙・外交での発生頻度や長期結果は未評価。
