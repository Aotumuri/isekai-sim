# 国家戦略AI：調査・設計記録

状態：調査・ベースライン測定中。新AIはまだ実装・有効化していない。
基準リビジョン：`394d4bd`。作業ブランチ：`codex/war-campaign-strategy`。

## 現行の意思決定経路

`update.ts` の slow tick で外交、和平、宣戦、予算、動員、補給、生産を
更新した後、次の順に陸上AIを更新する。

1. 物理戦線・作戦区画、距離場、地形接続、補給切断分析。
2. 補給防衛、補給救援、首都防衛。
3. 国家戦線計画、撤退、首都危機による攻勢中止。
4. 戦略予備、再編成、進展評価、膠着圧力。
5. 兵力配分、前線カバレッジ、攻勢作戦、上陸計画、崩壊追撃。
6. 戦略脅威観測、対脅威連合。

fast tick では `nation/reposition-units.ts` が移動を決め、海上移動、
戦闘、占領、首都更新、降伏が続く。プレイヤーの直接命令を持つ陸上部隊は
通常AIの部隊集合から除外される。上陸専有部隊には既存の例外がある。

戦線計画は戦線・指標・首都防衛・補給防衛・上陸作戦の version によって
再計算を省略する。新しい戦略入力を追加する場合、このキャッシュにも
変更を伝播させる必要がある。

## 現時点で確認した構造と仮説

|分類|コード上の根拠|評価・扱い|
|---|---|---|
|設計上の欠陥候補|`campaign-objectives.ts` が現在の和平要求領土を返す|外交要求と持続的な内部目的が同一。交渉更新で目的が変化し得る|
|設計上の不足|`nation-front-plans.ts` が各区画を個別評価|国家の全交戦相手を通じた持続的な優先順位が必要か実測する|
|既存機能の再利用|`stalemate-pressure.ts` は国家・敵国別に重点を保持|重点選択を二重実装しない。既存の維持期間・変更幅を尊重する|
|競合候補|作戦候補順位は救援、切断、包囲、縮小、重点、戦線優先度の順|戦略の数値優先度を足すだけでは上位目的が作戦に届かない|
|競合候補|予備・再編成が配分より先、作戦が配分より後|作戦準備の部隊リースと緊急防衛の優先関係を維持する|
|観測不足|標準ベンチマーク世界は外交・動員等を無効化|和平・開戦判断や通常自律世界の品質をこの結果から推定しない|
|問題ではない仮説|配分には最低部隊数、距離、移籍ペナルティ、準備リースが存在|「配分が全く無計画」とする説明は不正確|
|問題ではない仮説|和平は疲労、食料、損耗、戦況傾向、他戦争を既に考慮|和平ロジック全体の置換は不要。内部目的との接続を検討する|
|未判定|戦闘・占領・降伏のゲームバランス|AI変更と分離して診断。係数変更を先行しない|

これらは戦略的品質の低さを実証した結論ではない。実装上の不具合と
バランス上の問題は、シード別の状態推移を確認してから確定する。

## 次の設計で守る境界

国家戦略は目的、継続方針、予算、戦線役割を保持する。戦線・作戦層は
それを実現可能な配分・候補に変換し、既存の戦術層が移動・戦闘を実行する。
首都と重大な補給危機、撤退、プレイヤー命令を戦略が妨げてはならない。

全国家に一律の攻撃方針を課さず、外交要求を変更しても内部目的が自動で
書き換わらない構成を検討する。維持期間だけで計画を固定せず、目標消失、
戦争終結、緊急防衛、資源制約の変化を理由付きで再評価する。

`maxActivePerNation: 1`、戦闘ルール、生産量は基準比較中に変更しない。
効果が未実証の機能は既定で有効にしない。
