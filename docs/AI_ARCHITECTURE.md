# 国家戦略AI：調査・設計記録

状態：持続的国家計画の試作を実装。既定では無効。統合・新旧比較は継続中。
基準リビジョン：`394d4bd`。作業ブランチ：`codex/war-campaign-strategy`。

## 現行の意思決定経路

`update.ts` の slow tick で外交、和平、宣戦、予算、動員、補給、生産を
更新した後、次の順に陸上AIを更新する。

1. 物理戦線・作戦区画、距離場、地形接続、補給切断分析。
2. 補給防衛、補給救援、首都防衛。
3. 国家戦線計画、撤退、首都危機による攻勢中止。
4. 戦略予備、再編成、進展評価、膠着圧力。
5. 兵力配分、前線カバレッジ、攻勢作戦、上陸計画、崩壊追撃。
6. 戦略脅威観測、対脅威連合。

fast tick では `nation/reposition-units.ts` が移動を決め、海上移動、
戦闘、占領、首都更新、降伏が続く。プレイヤーの直接命令を持つ陸上部隊は
通常AIの部隊集合から除外される。上陸専有部隊には既存の例外がある。

戦線計画は戦線・指標・首都防衛・補給防衛・上陸作戦の version によって
再計算を省略する。新しい戦略入力を追加する場合、このキャッシュにも
変更を伝播させる必要がある。

## 現時点で確認した構造と仮説

|分類|コード上の根拠|評価・扱い|
|---|---|---|
|設計上の欠陥候補|`campaign-objectives.ts` が現在の和平要求領土を返す|外交要求と持続的な内部目的が同一。交渉更新で目的が変化し得る|
|設計上の不足|`nation-front-plans.ts` が各区画を個別評価|国家の全交戦相手を通じた持続的な優先順位が必要か実測する|
|既存機能の再利用|`stalemate-pressure.ts` は国家・敵国別に重点を保持|重点選択を二重実装しない。既存の維持期間・変更幅を尊重する|
|競合候補|作戦候補順位は救援、切断、包囲、縮小、重点、戦線優先度の順|戦略の数値優先度を足すだけでは上位目的が作戦に届かない|
|競合候補|予備・再編成が配分より先、作戦が配分より後|作戦準備の部隊リースと緊急防衛の優先関係を維持する|
|観測不足|標準ベンチマーク世界は外交・動員等を無効化|和平・開戦判断や通常自律世界の品質をこの結果から推定しない|
|問題ではない仮説|配分には最低部隊数、距離、移籍ペナルティ、準備リースが存在|「配分が全く無計画」とする説明は不正確|
|問題ではない仮説|和平は疲労、食料、損耗、戦況傾向、他戦争を既に考慮|和平ロジック全体の置換は不要。内部目的との接続を検討する|
|未判定|戦闘・占領・降伏のゲームバランス|AI変更と分離して診断。係数変更を先行しない|

これらは戦略的品質の低さを実証した結論ではない。実装上の不具合と
バランス上の問題は、シード別の状態推移を確認してから確定する。

## 次の設計で守る境界

国家戦略は目的、継続方針、予算、戦線役割を保持する。戦線・作戦層は
それを実現可能な配分・候補に変換し、既存の戦術層が移動・戦闘を実行する。
首都と重大な補給危機、撤退、プレイヤー命令を戦略が妨げてはならない。

全国家に一律の攻撃方針を課さず、外交要求を変更しても内部目的が自動で
書き換わらない構成を検討する。維持期間だけで計画を固定せず、目標消失、
戦争終結、緊急防衛、資源制約の変化を理由付きで再評価する。

`maxActivePerNation: 1`、戦闘ルール、生産量は基準比較中に変更しない。
効果が未実証の機能は既定で有効にしない。

## 試作の責任分担

`war-campaign/state.ts` が国家ごとに全交戦相手をまとめた計画と、
理由付きの変更履歴（最大200件）を保持する。`objectives.ts` は開戦時の
最後通牒または初期国境目標を保存し、防衛国は自領保全を目標とする。
海上戦争では国境がないため、現試作は相手首都を目標の代替にする。
これは最終設計として妥当か未検証である。

`policy.ts` は国家全体の戦力比、損耗、食料の残存時間、補充資源、
首都危機、目的達成、国家の性格から防衛・限定攻勢・確保・和平志向を選ぶ。
`update.ts` が80 fast tick の維持期間と緊急再評価を管理する。
優先相手は未達成目標のある交戦相手から戦力負担を比較して選び、
小さな戦力差で交代しないよう現相手を優遇する。

`front-guidance.ts` が通常攻勢の許可と戦線優先度に反映する。
局所的な撤退、首都・重大補給の防衛、橋頭堡は既存判断を優先し、
必要兵力の防衛下限や部隊命令を直接書き換えない。
計画versionが戦線計画のキャッシュに伝わり、既存兵力配分へ届く。
内部目標は `getCampaignObjectives` に渡されるが、和平要求の変更に追従しない。

`SimulationSettings.warCampaignEnabled` を明示した場合だけ動く。
比較診断は `--campaign` で指定する。`formatWarCampaignSummary` により
現在方針、優先相手、目標、達成状況、計画変更理由を文字列で観測できる。

未統合：和平の評価、宣戦前の計画可能性、予備・再編成の共通予算、
生産需要、上陸と海軍の優先順位、作戦順位の上位目標との調整。
現時点では試作全体の戦略的合理性・品質を実証していない。

## 試作1の棄却と試作2

目標保持率・終戦の比較で試作1の全国一律の攻勢抑制を棄却した。
試作2では既存の局所攻撃継続条件を満たす防衛的な機会と、準備・実行中の
作戦を尊重する。交渉による出口のない旧式・強制戦争では、限定目標を
達成しても軍事的終結への経路を閉じない。
戦線方針が変更された場合、既存の兵力計算をその方針で再評価し、
供給・首都等の防衛下限を維持する。輸送船内の部隊も国家の戦力に含める。

`peace-guidance.ts` が、和平後の目標確保と許容コスト超過による出口の価値を
既存の和平評価に渡す。外交要求の自動書き換えは行わない。
宣戦・予備・再編成・生産・上陸・海軍との共通予算の統合は引き続き未完了。

## 共通兵力・補充予算と海上の接続（試作3）

`force-budget.ts` は同じ戦略tickで予備編成と再編成が戦線から引き抜く
兵力を一つの台帳で管理する。各機構の既存適格条件・最低兵力に加えて、
実際の残存戦力とカバレッジ下限を確認する。戦線配分更新時・次tickに
再構成し、撤退・再編成・予備に既に移った兵力を二重に数えない。
緊急予備展開を制限する処理ではなく、新たな通常引き抜きだけを制限する。
プレイヤーの直接命令がある部隊は引き抜かない。

`production-budget.ts` は実行中で補給可能な再編成が次のtickに使う
補充資源を、新規陸海軍生産より先に確保する。既存の補充速度・施設倍率・
実際の不足量を使う。到着前・完了済み・孤立中の再編成には確保しない。
資源収入・消費単価・動員上限・生産頻度を変更せず、補充と新規生産の
優先順位だけを接続する。前tickの計画を使うため初回の新規再編成への
確保は次回生産からとなる。

上陸候補の既存「近隣の味方目標」評価へ国家目標を渡す。海軍の攻勢任務は
主敵を既存の任務変更幅に相当する分だけ優先し、護衛・迎撃・緊急任務の
優先度や継続期間を変更しない。既に確保した上陸航路を方針変更で取り消さない。

既存の D キーの設定 → Strategic summary に国家方針・目標・優先相手・
変更理由・現在作戦と直近の結果を表示する。最大6国家・各3目標に抑え、
主要画面に新たな操作を追加しない。文字列の検証は実施するが、ブラウザでの
目視確認はまだ実施していない。
