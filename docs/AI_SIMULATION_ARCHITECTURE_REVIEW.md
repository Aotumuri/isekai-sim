## 1. 要旨と、目指す世界

**提案。** 判断の質を「当時知り得た情報のもとで、誰が何を守ろうとし、何を諦め、その結果を引き受けたか」で評価する。たとえば、同じ限定和平でも、港の領有が確定して選挙前に撤兵する国と、保護国を見捨てる政治的費用を理由に拒む国があってよい。観察者が判断時点の違いを読み取れ、その判断が実際の条約や配分に効くことが目標になる。

## 5. 国家戦略と軍事指揮の接続案

**提案。** 目的の所有者、決定権、実行担当を次の境界に置く。新しい常時計画器は要らない。

| 責任 | 保持・決定するもの | 既存系への受け渡し |
|---|---|---|
| 政府 | 少数の国益案件。主体・対象・根拠となる請求/条約、望む政治的結果、許容負担、再審条件、終了条件 | 平時には危機・交渉・見送りを比較。開戦時に案件を既存の開戦意図へ関連付け、当時の目標を固定。政権交代時の改訂は履歴に残す。 |
| 軍中央 | 既存WarCampaignが相手別の手段と国家全体の予算・優先順位を決定。政治的妥協と交渉中の軍事努力を並行して保持 | 戦線計画に対象・最低限維持する任務・使用可能な余力を渡す。複数戦争で同一部隊を二重計上しない。 |
| 戦域の責任者 | まず既存戦線計画の任務として、対象地域、担当、現行版、達成・解除・再審条件を持つ。人物は後付け可能 | 配分器が既存作戦・退却・予備・手動命令と調停。受理、部分充足、実行不能とその理由を返す。移動の書き手は既存系に限る。 |
| 外交・戦後 | 既存講和系が相手に成立する条項と継戦の期待利益・追加費用を比較。終戦後も国益案件に結果を戻す | 開戦時の要求、一時占領、法的領有、従属関係、後日の存続を別記。休戦による保護不能期間も維持費用に含める。 |

最小の縦断例は既存の一地域の請求。請求強度の変化 → 外交で要求または見送り → 限定目標 → 合法な割譲案 → 所有確認を一つの参照で追う。成立しない割譲、相手の拒否、負担超過なら別の合法案・撤退を選べる。傀儡保護は二例目とし、戦後に援助可能・介入不能・すでに共同交戦中を区別する。資源への関心はまず既存産地の価値で表し、新条約は現行の結果では表現できない場合に限定する。

## 6. 個性・国内政治・指揮官・制度間対立

**確認。** `nation-character.ts:getNationCharacter` は世界seedと国家IDから安定な初期傾向を得る。攻撃性・協調・革新・倹約があり、政治側は政権の政策を性格に反映する。`factions.ts:factionWillingness` は協調性等を加盟義務の判断に、キャンペーンは攻撃性を損失許容に使う。個性は既に行動へ届いている。

**提案。** 国家には「何を価値とするか」、政権には「任期・連立を通じて何を負担できるか」、軍には「与えられた目的をどう遂行したいか」を持たせる。同じ和平案に対して、兵力離脱が増えた政権は支持低下を避けようとし、軍は未完任務と組織の評判から継続を求め得る。政府が最終判断し、採決・更迭・受諾が既存支持や次の任用に返る場合だけ対立を状態化する。既払費用による政治的圧力と、これからの軍事費用は別々に記録する。

最初の指揮官は国に少数、職位に一人。担当範囲、能力（見積り誤差・実行可能性判断）、作風（許容された代案の選好）、忠誠、軍内支持、任命主体を持つ。同じ目標と能力制約の下で慎重な指揮官は余裕を多く残し、別の指揮官は不確実な機会を採用し得る。能力は未知の敵情を透視する権利にはしない。意思決定時点の観測範囲・時刻・確度を保存する。経験は任務完了等の節目で更新幅と上限を設け、国籍で固定しない。

長期には失敗で降格しても部下の支持を保つ、政府が後任不足や軍内反発を恐れて留任させる、といった選択を可能にする。拒否は命令受領時に根拠と権限を記録し、政府側の受忍・交代・処分に支持と任務継続の費用を課す。内戦が実際に発生した場合に限り各職位が支持する当局を選び、部隊帰属は既存内戦処理で一度だけ変更する。人事だけが頻繁に変わり、同一状態で選択も政局も変わらなければ実装を広げない。

## 7. 命令継続・遅延・兵力の生命周期

**提案。** 任務は組織に帰属し、指揮官はその時点の権限者とする。交代・不在時も現行命令と経路は有効。副官または職務代行が既定の範囲で継続し、新任が変更した場合だけ版を進める。戦線の分割・統合には目的地域と既存の幾何対応を使い、対応が曖昧なら再審する。所在はまず担当戦域だけでよい。移駐・負傷・不在により権限委譲や観測時点が実際に変わる段階でのみ司令部の地域を追加する。

改訂は目標消滅、重大な脅威、実行不能、または現在の任務を放棄する費用を上回る代案で行う。切替費用には既存の距離差に加え、失う行軍進捗・引継ぎに要る時間・出発元の欠員を、同じ費用を二度数えず含める。待機期間で袋小路を固定しない。局所的な退却・手動命令・緊急対応は即時。遅延は安定性が確認された後に、戦域を越える方針変更一種類で試す。発令・受領時刻と版を分け、上書き済み命令は到着時に棄却する。観察者に予告できる帰結がなく、応答不能時間だけ増えれば廃止する。

復員はまず現行の平時条件を維持。将来は合法な候補の中で任務未割当、代替可能性、経験・装備、元任務への補充到着、解放できる人員・資材を比較する。前線不足のまま後方募集が続くなら、戦闘による離脱、既存部隊の回復、補給、補充の到達見込みを順に調べる。戦時整理を導入するのは、組織を維持する費用と整理の便益をゲームが表現でき、撤収から人員返還まで保存則が検証できる場合に限る。

## 8. 判断状態に基づく観戦UI

**確認。** `src/render/war-campaign-debug-summary.ts:formatCampaignDebugLines` は実際の方針・改訂番号・理由・候補・制約・作戦進捗を表示する。`updateWarCampaigns` の変更イベントは最大200件。一方、候補は再評価時にも更新されるので、現在の上位案を過去の採択理由として表示すると時点を取り違える。

**提案。** 国を選ぶと「守りたい結果／現在の手段／直近の変更理由」を表示し、展開すると決定時のtick・主体・案件・命令版、採択案と次点、制約・不確実性、誰が受理したかを読めるようにする。地図では担当戦域と未充足の任務を選択時だけ表示。交渉では自国の要求と相手側の実際の受諾判定を分け、当時知らなかった相手の情報には観戦者向けと明記する。指揮官・対立は該当する決定が存在する場合だけ表示する。

## 10. 将来の評価方法

**提案。** 試験開始前に変更の主張・対象・判定条件を登録する。R2の採否・凍結条件・最終保留集合はそのまま維持し、次の観点を今後の研究に追加する。

| 評価するもの | 最小の比較と読み方 |
|---|---|
| 正しさ | 同一入力の境界テスト。例は分母のみ変化、新規実損、戦争終了。保存則・合法性・手動保護・決定性を必須とし、修正の波及と戦略優位の主張を分けて報告。 |
| 戦略的一貫性 | 改訂前後の既知情報・理由・次点を記録。同一目的で状況不変の反転、重大な変化に反応しない例を対で検討。長く維持しただけでは合格にしない。 |
| 目的指向性 | 開戦前案件から法的な終戦結果・戦後の存続まで追う。実行可能な見送りも標本に含める。未成立提案・途中占領・終戦未到達は別集計。 |
| 組織の安定 | 存続する任務あたりの不要な中断時間、保護すべき任務の欠員時間、発令から実効到着まで、未充足・不能理由。戦線消滅や正当な退却を除外。 |
| 個性・制度 | 同一状態で傾向または権限関係を一要素だけ交換。予告した価値対立で選択が分かれ、制約が厳しい場合は一致も許す。役名と無関係な乱数差を検出する。 |
| 説明・面白さ | 事前に普通・膠着・失敗を含む観戦区間を抽出し、候補名を伏せて「目的・変更理由・意外だった帰結」を観察者に記述してもらう。決定記録との一致、誤読、異なる歴史に至る過程を残す。突破・包囲などの発生回数に報酬を置かない。 |
| 性能 | 同一状態の判断費用と異なる軌跡の総費用・メモリを第9節の方法で別に測る。 |
| 競争結果 | 同じ初期世界で基準同士、候補攻撃側のみ、候補防衛側のみ、候補同士を比較。第三国の実装・外部開戦条件を固定し、同じ役割同士を対応付ける。世界全体の相互作用を見る両側更新も残す。 |

機序の再現にはまず既存の一対と反例一対。集団への主張は別に、シナリオ・役割、実用上区別したい差、主要指標を事前指定し、既存の対間不一致率から必要な**独立世界数**を見積もる。同じ世界の連続窓を独立件数に数えない。稀なイベントは曝露と不成立を全例報告し、足りなければ判定保留。少数例による設計判断、未使用開発例での再現、候補固定後の正式判定を段階化する。自然な外交を問う段階では外部固定開戦とは別枠にする。
