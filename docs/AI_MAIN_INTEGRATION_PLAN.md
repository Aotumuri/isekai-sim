## 既定オフの境界と最小の追加検証

- **実行・計測**。設定は optional。未指定で slow tick の updateWarCampaigns は距離キャッシュと world.warCampaigns を消して戻る。計画の作成・全軍予測は行わない。一方、移動で WeakMap の消去、戦闘で損害観測関数の呼出し、通常講和で評価用関数・一部の集合の生成は残る。UI も静的に配布される。計測器ありなら時間の採取も残る。B の受入時には「観測なし／時間計測のみ／イベント観測あり」で同じ開発入力を1回ずつ比較する。
- **旧状態と途中切替**。src 内にワールドをファイルや localStorage から保存・復元する製品経路は確認できなかった。既存セーブの実機読込み互換は未検証。古い WorldState 形状と永続セーブは区別する。実験基盤を提案する時点で、設定・目標・観測の新フィールドを欠く fixture を1つ、要求中のオン→オフ→講和→再オンを1つ通す。既存の所有権・手動条項・目標履歴・キャッシュ再生成を照合する。外部に正式な保存形式があればその実物を使う。
- **外交・戦闘・手動操作**。war-negotiations、player-nation、campaign-diplomacy、land-fronts は手動政策・命令の一部を網羅。quick は短い戦争用シナリオ。関連系を移す単位ごとに、通常外交の危機→宣戦→講和を通る既知の開発例と、交戦中に一部隊を手動指揮する例で main とオフ版を対照。命令・経路・交戦双方の損害・提示条項・決済・所有権・乱数を同じ tick で確認。UI を動かす単位では実ブラウザーでスイッチ、選択国の切替と手動受諾を確認する。
- **長時間・メモリ**。既存の試作7では6件の長時間走行で終盤GC後38.14–43.09 MiBとの記録がある。現HEADの全差分・通常設定の対照ではない。状態を保持する基盤を移す場合に限り、同じ通常規模・開発シード1本を両版で反復し、平時・戦時・終戦後の tick 時間、GC 後 heap、計画数、履歴上限（計画イベント200、完了目標100）、UI停止後の解放を測る。差が反復する場合に対象を広げる。今回、全行列・予約済み最終評価シードは使用していない。
