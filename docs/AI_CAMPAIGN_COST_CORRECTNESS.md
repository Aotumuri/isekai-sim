# 戦費予測の分母変更に対する会計修正

## 正しさの判定条件

現行版と保存済み R2.25 パッチを比較する。戦争の追加・終了で分母だけが拡大・縮小した場合、同じ物理損失の観測から新しい損失率を発生させず、既存の率を換算して減衰させる。分母が変わる観測と同時に生じた実損も取り込む。分母一定、観測履歴なし、初期兵力しか記録していない旧目標でも計算が定まることを確認する。累積損失の分子・許容上限・予測時間・戦闘ルールは現行仕様に従う。

保存パッチの統合回帰を現行版で失敗、修正版で成功と確認する。同一入力からの再生一致とキャンペーン無効時の一致を小規模に確認する。既存の戦略評価は [R2.25](AI_R2_CAMPAIGN_COST_BASIS.md) に従う。ソースが固定候補と一致する場合は、その60件の比較を参照する。最終評価用シードは使用しない。

## 採用と検証

会計修正として採用。保存パッチ適用前は並行戦争終了の統合回帰が失敗し、修正後は成功した。拡大時の減衰、旧目標の分母、初回観測、分母変更と同時の実損も検査した。修正後の `src/` は固定候補 `de5fbf4` と一致する。

膠着の開発シード 822748319788 を 6,300 fast tick 再生。tick 6200 の30秒予測は 100% から約 0.00369% となり、その時の方針は両方とも講和志向だった。各 slow tick の状態要約・キャンペーン・乱数系列から作ったハッシュは、無効時に旧版と一致し、有効時は同一版の再生2回で一致した。回帰730件（型検査込み）、build、quick benchmark に成功。保存済みの開発60件では開戦戦争の全結果が一致し、後発戦争は2件変化した。膠着時の防衛側存続の改善は確認されておらず、R2.25 の戦略不採用判定を維持する。
