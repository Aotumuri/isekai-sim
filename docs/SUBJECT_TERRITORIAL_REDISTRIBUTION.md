# 講和後の属国への領土再配分

宗主国は、講和、降伏、最後通牒や領土交換で法的に取得した地区を審査し、直轄を続けるか既存の属国へ割譲するかを決める。属国側も追加の領土を引き受けられるかを評価する。結果は既存の世界履歴に表示される。

## 審査する地区

- 地区ごとに最新の法的取得を一件記録する。同じ取引の地区は取得情報を共有する。新しい割譲や革命で所有者が変われば、古い記録は失効する。占領の開始、属国への再配分、国家統合、亡命政府の領土回復、新設政府への当初の割当は審査を起動しない。
- 取得時に宗属関係が存在し、審査時にも宗主国と属国が活動中であることを求める。宗主国自身が属国になった場合や、対象地区が宗主国の首都になった場合は失効する。プレイヤーが既存の手動設定で運営している政府は自律審査の対象外となる。
- 講和・外交・開戦処理が済んだ後、100日周期で審査する。取得から少なくとも100日を置き、戦争、占領、進行中の領土要求、交換提案があれば保留できる。取得から1,100日以降は期限切れになる。最終決定後は、別の法的取得があるまで再審査しない。
- 現に属国が領有・支配する地区と陸地で接続する候補を作る。同じ取得の連結成分と、その中で州ごとに連結する地区群を比較する。既存の講和時の境界判定を使い、国の陸地成分や分割される州が切り離される案を除く。海路による接続や首都間の距離から陸の隣接を推定することはない。
- 候補は地区の連結成分と実際に隣接する属国から生成し、上位8件まで境界・取引を審査する。一度の審査で最大一つの地区群を一つの属国へ渡す。残った地区は直轄となる。審査順と同点処理は固定で、乱数は消費しない。

## 両政府の判断

宗主国は、地区の人口で重み付けした制度的排除、隣接境界の比率、信頼、国内の不満を評価する。住民の祖先・文化・信仰そのものの違いでは割譲を決めず、双方の集団別待遇、強制移動、宗教制限、直轄時の地区協定を参照する。市街、港、戦略資源、農業・灌漑に価値があれば直轄を選ぶ余地がある。周辺国の対外関係と利用可能な補給情報、両政府の陸上戦力も考慮する。

属国は生産、食料事情、人口、支援に依存できる度合いと、制度的排除、既存の不満、防衛負担を比較する。追加の地区数と人口を現在の規模で割り、正統性や行政上の余力と照合する。受け入れ能力を超える候補は実行できない。新たな行政費用や予算科目は作らず、地区の移転後は既存の税収、生産、食料、支援、政治の処理が所有権を参照する。

宗主国が提案に値すると判断し、属国側でも便益が上回れば合意となる。拒否された場合でも、国内自治協定がなく、独立圧が低く、宗主国に軍事的な優位と信頼があり、属国側の負担も許容範囲なら、宗主国が移転を押し付けることがある。合意時は信頼と好感度が高まり、押し付け時は負担に応じて信頼と好感度が下がり、緊張が高まる。拒否だけで外交関係に罰則を適用することはない。割譲条件の対案は扱わない。

同じ面積の増加でも、信頼が高く宗主国の支援・防衛に価値がある場合と、属国が独立を望み自力で防衛できる場合とでは、宗主国の評価が変わる。移転後の領土比は次回以降の属国自治審査に反映される。独立、国内自治、統合は既存の政治交渉を経る。

## 政治的・経済的な継続

実行時に宗属関係、戦争、占領、首都、現在の所有者を再検査し、既存の領土移転で地図・州・請求権・部隊の合法的駐留を更新する。地区の人口、建物、農地、進行中の産業復旧と併合抵抗は引き継ぐ。国庫、備蓄、研究、部隊の所属は元の政府に残る。

地区自治協定は前の政府との契約なので法的効力が終了する。現地の不満と長期の記憶は残り、新政府の待遇に応じて既存の更新で変化する。新政府との自治協定が必要なら、地区はその政府に要求を出す。決定イベントには地区ID、政府、合意・押し付け・拒否・直轄の別、主な理由、信頼の実変化を記録する。候補ごとの内部評価は世界履歴に掲載しない。

## 検証と制約

連結成分と州ごとの候補に範囲を絞っているため、同じ州内の部分集合や複数の属国にまたがる最適な分割を網羅することはない。補給は有効な既存の評価がある場合に参照する。産業・防衛・自治の評価は現在の制度と能力からの推計であり、数十年先の発展や独立を予測して確定させるものではない。
