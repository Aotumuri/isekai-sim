# 地域自治交渉と属国の政治判断

地区と属国の要求を100日周期で審査する。中央政府、地域運動、宗主国、属国政府は、それぞれが得る利益と引き受ける負担を比較する。世界の日付や無作為列は交渉のために変更しない。

## 地区の要求と合意

要求の単位は既存の地区。地区は集団別人口と不満をすでに保持しており、分割される州をまたぐ新たな政治単位を持つ必要がない。短期の反発に加えて長期の記憶が残り、現在も制度的な排除が続き、主要な被影響集団が地区人口の20%以上を占める場合に、地域運動が要求を出せる。政府は一周期に全国で最も重い候補一件を受け付ける。少数集団の存在や多様性のみでは要求は生じない。

祖先・文化・宗教の集団を対象とする制度上の保護を要求できる。文化・宗教については、当事者がまとまった人口を占め、不満が高い場合に当該制度の現地管理を要求できる。中央政府は地区の不満、対象人口、正統性、イデオロギー、支持率、協調性、体制、首都の行政上の重要性、戦争と食糧不足を考慮する。全面受諾、保護だけの提案、拒否があり、戦時の不足が深刻な場合は一度だけ延期できる。地域運動は提案を翌周期に審査する。排除と不信が強い場合、保護だけの提案を拒否することがある。国の改革で要求が満たされた場合や支持基盤を失った場合は要求を取り下げる。

| 合意 | 地区の制度への効果 |
| --- | --- |
| 制度上の保護 | 対象集団に対する同化・権利制限・包括的な宗教禁止・強制移動を適用しない |
| 文化・宗教制度の現地管理 | 対象集団を保護し、地区の当該次元で政府主導の同化を停止する |

合意は履行中の各周期に効き、不満の短期成分と長期成分は既存の速度で減衰する。全国の正統性には地区人口を重みにして反映する。同一集団に対する全国待遇が新たな同化や制限へ変わると、中央による合意の撤回として扱う。拒否と撤回は地区の不信を強める。不信は上限を持ち、時間とともに下がる。合意の履行中は低下が速い。交渉が不成立になった後は1,000日の間隔を置く。拒否は地区内の集団と要求の種類ごとに記憶し、別の集団が提起しても同じ要求の拒否は残る。同じ要求の再提起には政権、対象集団への待遇、排除の強度または支持基盤の変化を要する。全国の制度で既に満たされた要求は提起しない。

占領は交渉と合意の適用を一時停止する。法的な領有者が変わると旧政府との合意は終了し、蓄積した地区の不満は残る。歴史には要求、提案、成立、決裂、違反を記録する。国家政治画面と地区ツールチップで対象集団、要求、提案、状態、判断理由を確認できる。地区の不満は既存の革命発生地の評価と、祖先集団に関わる国外の再統一運動の評価に使われる。革命や開戦には引き続きそれぞれの成立条件を要する。

## 属国と宗主国

独立圧は継続して計算する。食糧、徴収、工業支援、軍事・領域規模、宗主国の国内支持、信頼、制度的不満、自治への合意が影響する。圧力が高いと、保護の価値や自立能力を考慮したうえで属国が自治や独立を提案できる。宗主国は戦争への関与、政治的余力、支配の費用、徴収の価値、軍事的優位、政権の性格を基に判断する。独立に反対する宗主国が自治を対案に出し、属国が受諾または拒否する経路がある。決裂は信頼に影響する。休戦の終了や戦況などに意味のある変化があれば、1,000日の間隔を経て再提案できる。

- **国内自治**を認める合意では、宗主国による国内行政の変更権限と公認集団への制度的影響を止め、収穫徴収率に上限を設ける。工業支援を増やせる場合は、既存の輸送経路と備蓄制約の下で鋼材・燃料の配送上限を引き上げる。徴収率の上限を超えると合意が失効し、信頼が下がり、独立圧が高まる。
- **協議独立**では、属国は政府、領土、部隊、資産を維持し、宗主国との休戦を結ぶ。
- **単独独立**では、交渉が成立せず、属国が休戦に拘束されておらず、自力で離脱できると判断した場合に独立を宣言できる。宗主国の軍事対応には政権の方針、国内支持、他の戦争、軍事力、既存の開戦制約が作用する。独立を見送る場合は宗属関係を維持する。
- **平和統合**では、宗主国が行政費用と協力の利益を比較して提案し、属国が保護・経済協力の価値と国内支持・自治を失う負担を比較して承認する。文化の一致は両政府の判断材料の一つ。長期間の宗属関係と平時の安定を要し、承認後にも信頼、自治圧、領域支配、稼働中の志願部隊を検査する。双方が承認した統合は、既存の領土移転と国家継承の手続きを通じて処理する。既存の手動の共通行政手続きは従来の条件を使い、属国の国内自治協定がある場合は双方の承認が必要になる。

全国の行政方針、地区の集団別協定、宗属関係の国内自治協定は別々に適用する。属国の政治判断と協定は政治画面から観察できる。最近の判断を一組ごとに保持し、重要な転換は世界履歴にも記録する。

## 計算量と範囲

地区交渉は既存の地区統治集計に同居し、地区につき交渉または合意を一件だけ保持する。属国の審査は属国が存在する周期に限り、地区数、占領、交戦相手、関係国の部隊戦力をまとめて集計する。保護・支援・領土移転は既存の制度と資源会計を使用する。

連邦議会、地区の独自課税、自治協定の第三国保証は扱わない。要求は最も大きな排除要因を持つ集団を代表する簡易モデルで、複数集団の共同交渉や地区間の組織化は扱わない。全国の待遇を再変更した際に、既存の地区協定を個別に維持する条項はない。性能と固定シードでの結果は[自律世界の長期診断](LONG_TERM_WORLD_DIAGNOSTICS.md)を参照。
