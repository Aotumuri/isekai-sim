# 兵員・工業・講和の監査

## 実測

## 生産・補充の制約

- 兵員は首都350、都市200を基礎に、地区の小地域数に応じてそれぞれ10、6ずつ加算する。歩兵・戦車の新編は各1,200を使う。編制上限や配備条件もあるため、新編数は兵員備蓄から直接決まらない。この試行で兵員の中央値は一編制の補充量を1 slow tick 未満で産出した。
- 鉄鋼4 / 鉱床、燃料3 / 鉱床、戦略鉱物2 / 鉱床が基礎産出。武器工業の基礎能力は首都8、都市4で、武器1につき鉄鋼1を要する。研究が有効な場合、武器生産時に鉄鋼8を留保する。占領は都市・一般鉱床の生産を止め、稼働中の占領鉱山は一部の戦略鉱物を占領国に1供給する。
- 基礎の新編費は歩兵が武器10、戦車20、輸送艦8、戦闘艦18。戦車にはゴム・タングステン各3、輸送艦には銅・ゴム各2、戦闘艦には銅3・タングステン4を追加で要する。兵員費は輸送艦300、戦闘艦500。設計により武器費と維持燃料が変わる。基礎の燃料需要は戦車3、輸送艦2、戦闘艦4 / slow tickで、燃料鉱床1つで維持できる基礎戦車は1編制。
- 損耗の補充も資源を使う。既存の陸軍再編は、供給のある地点で人員と武器の備蓄から補充する。基礎上限は兵員48、装備1.25 / slow tickで、徴集した新品編制とは別に費用を負担する。
- 資源調整の優先候補は、武器の豊富な国の兵員産出を一律に下げることより、原料不足国と輸入手段、燃料不足時の稼働判定、募集・補充にかかる期間の検証。燃料は判定時点の備蓄が正なら機動部隊全体がその tick に稼働可能で、総需要を賄えるかという条件とは一致しない。

## 外交での規模

- 一括武器賠償は最大100、通常の AI 初期要求は支払国備蓄の30%か60の小さい方。上限100は基礎歩兵10編制分、または戦車5編制分の武器。標本の中央値では武器総産出の約6.3 / 8.8 slow ticks 分、160 tick 時点の中央値備蓄の約4.5% / 8.7%。武器産出ゼロの国には同じ金額でも別の意味を持つ。
- 軍事援助は5–50武器、既定・AI は20で、送付国は30を留保する。20は基礎歩兵2編制または戦車1編制分で、160 tick 時点の中央値備蓄の約0.9% / 1.7%。武器の産出ゼロの受領国には相対的に大きい。援助には設計の利用権も付く。人員・鉱物・稼働燃料は必要なまま。
- 継続賠償は1–10を30 slow ticks ごとに支払う。満期と同時の支払いがないため、300 / 600 / 900秒の停戦の最大総額は90 / 190 / 290。90燃料は基礎戦車30 slow ticks 分。World map の最終中央値備蓄56を超え、同時期に燃料を1,000以上備蓄する国もある。鉱床のない国の戦略鉱物の初期備蓄8に対し、満額の最初の支払いは10。したがって同じ条項でも継続可能性が異なる。

## 今回の変更

継続賠償の評価を、固定量に対する一律の減点から支払国の負担率に変更した。分子は満期前の全支払予定量。分母は、現在の備蓄と、最後の支払日まで直近の国内生産余剰が続いた場合に供給できる量の合計。国内余剰から機械燃料、武器生産に使う鉄鋼、新編で使う戦略鉱物を差し引く。貿易や賠償そのものの入金は国内生産余剰に数えない。初回生産前など生産データがないときは備蓄を使う。負担率の上限は100%で、既存の武器賠償と同じ25点の尺度に載せる。契約は従来通り、各支払時点の備蓄の範囲で支払う。

例として10燃料×9回は、備蓄180・余剰0なら12.5点、備蓄180・余剰2 / slow tickなら3.125点、備蓄も余剰もゼロなら25点の負担。固定式ではいずれも23.6点だった。余剰は直近1 tick の推定で、募集の間欠支出、今後の占領、海外供給契約、既存の賠償の支払予定までは予測しない。複数シードで戦時の蓄積・不足を追うまでは、生産量や援助量の定数を変更する根拠は限定的。
