# 国家戦略の観戦表示

外交・研究パネルの Territories に、選択した二国間の領土目標を表示する。最後通牒と戦時目標は発行時の請求から表示し、法的所有と占領を区別する。見送りはその時の得点・必要得点、該当する場合は連立支持と選挙の影響を示す。終結後は当時の法的保有と結果を表示する。

Debug の Experimental national plans には、現在評価中の代案、首都主戦線の現行計画・割当・理由フラグと、作戦に保存された指揮官の発進判断を表示する。個々の部隊の付け替え履歴は首都戦線診断で確認できる。

ブラウザーで Territories を開き、対象国を切り替えると最後通牒の承諾が可能になり、承諾後に法的保有0/1から終結時の保有1/1・目標達成へ更新されることを確認した。占領と白紙和平、選挙による閾値変更、指揮官の待機理由の表示は回帰で確認。回帰739件、リポジトリの型検査、build、quick benchmark が成功。別途実施したアプリ全体の厳格型検査には既存のエラーがあり、開始版 `8e5a439` と同じ診断が出た。
