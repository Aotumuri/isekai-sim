# R-001 燃料の国内赤字と国ごとの偏り

世界全体で生産量が稼働要求を下回っても、余剰が残る国と持続的に不足する国が同時に存在するかを、既報にない小規模シードで調べた。ソースは `6da36afa18cff9bc47a6ba0cbfc6b5054bf6eecd`、Node 24.22.1、各10,000日。条件ごとに `WORLD_FUEL_ACCOUNTING=1` の観測ありと、同じシードの観測なしを実行し、世界署名で観測の副作用を検査した。

| シード | 世界の燃料産出 | 稼働要求 | 稼働実支払 | 世界の期末燃料 | 工業調達で届いた燃料 | 観測あり／なし世界署名の先頭 |
| --- | ---: | ---: | ---: | ---: | ---: | --- |
| 103 | 14,473.71 | 144,894 | 9,472 | 4,607.34 | 946.55 | `d21ed315aadb` |
| 107 | 12,000.00 | 100,401 | 9,657 | 1,998.30 | 921.08 | `11fa515c930e` |

数値は10,000日間の積算（在庫のみ期末）。「稼働」は定期の部隊燃料要求で、燃料の研究・建設・移動等への使用は別。工業調達で届いた燃料は移転量なので世界産出に加算できない。両シードで世界署名は観測の有無で一致。保存残差が絶対値 `1e-7` を超えた周期と、国内の燃料実支払に対応しない稼働観測はともに0。

- **103**。期末の世界燃料の約98%を `nation-0` が保有（4,528.78）。同国の需要があった周期で要求・支払は423で不足0日。`nation-4` は要求73,287、支払0、不足8,880日。`nation-1` は要求59,591、支払3,343、不足8,780日、期末在庫2.07。
- **107**。期末の世界燃料の約99.8%を `nation-2` が保有（1,993.91）。同国の要求・支払はともに3,000で不足0日。`nation-3` は要求88,401、支払3,669、不足10,000日、期末在庫0.39。
- 小規模の2標本では、燃料産出は全稼働要求の約10%と12%。この差は産地から全量を届けても埋められない。一方、期末在庫の偏りが同時に観測された。期末在庫だけから、各時点で余剰が売却可能だったか、買い手の予算、到達可否、燃料の国別受取量は識別できない。国別の産出集計は稼働要求があった周期の観測に限られる。

## 次の検証

R-002 では `industrial-procurement.ts` の買い手・候補作成と発注時、`international-trade.ts` の到着・返還時に、買い手別・資源別の観測を追加する価値がある。現状の `attempted` は候補を選んだ後に増えるため、国内不足のうち最初から候補がないケースは計上されない。経路なしは戻り値で区別できる。既存の成功・返還カウンタは着荷を世界単位で数えている。候補なし、経路不成立、条件不一致、着荷をそれぞれ一つの固定条件で再現し、観測あり・なしで世界署名の一致を検証する。

## 再現

```sh
for seed in 103 107; do
  python3 agents/tools/runner.py start "fuel-$seed-observe" \
    --revision 6da36afa18cff9bc47a6ba0cbfc6b5054bf6eecd \
    --timeout 180 --cpu-seconds 120 --reuse-node-modules \
    --env WORLD_FUEL_ACCOUNTING=1 --env WORLD_SIGNATURE=1 -- \
    node --expose-gc --import tsx test/diagnostics/long-term-world.ts quick "$seed" 10000
done
```

対照はジョブ ID を変え、`--env WORLD_FUEL_ACCOUNTING=1` を外す。実行時は既定の Homebrew Node が `libsimdjson.33.dylib` を読み込めなかったため、インストール済みの Node 24 を絶対パスで指定した。成功ログの ID は `R-001-{103,107}-node24` と `R-001-{103,107}-control`。監督プロセスで計った経過時間は観測あり9.23秒、4.23秒、観測なし8.81秒、3.84秒。時間性能の比較は目的外で、同時実行の影響を分離していない。委任なし。セッションのトークン・購読枠・クレジットは未取得。起動後の実験実行中に人による介入はなかった。
