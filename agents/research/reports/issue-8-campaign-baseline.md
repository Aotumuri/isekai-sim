# 現行版の国家戦争計画と首都防衛の観測

[Issue #8](https://github.com/Aotumuri/isekai-sim/issues/8) の開発シード3件。診断は `f2517ee`、初回の起動確認は `d5c074b`。旧 R2.19–24 では、行軍・固定守備・救援の候補に攻撃目標の喪失や防衛側滅亡とのトレードオフがあり、採用されなかった。今回は暦、敗走、燃料などが変わった現行版の挙動を観測した。旧版の数値との効果比較は行っていない。

## 再現と判定

Node 24.22.1、640×360、国家戦争計画と敗走を有効にし、1 fast tick を1日とする。以下を同一マシンで逐次実行し、各行を末尾に `trace` を追加して再実行した。各実行の上限は60秒、ジョブ全体は370秒。最終評価用シードは未使用。

```sh

node --expose-gc --import tsx test/benchmark/campaign-integration-smoke.ts stalemate-breaker 822748319790 2500 default default
node --expose-gc --import tsx test/benchmark/campaign-integration-smoke.ts reorganization-heavy 822748319792 2500 default default
```

仮説は、守備空白の発生を目標変更と実行上の制約に切り分けられること。同じ国の戦略・軍事方針・優先相手の組が80日以内に A→B→A と戻る箇所を抽出し、交戦構成、首都脅威、政体、領土版、燃料の有無を照合した。再現性の判定には、100日ごとと終了時の世界・乱数・講和、国家計画・請求履歴の署名、および終了時の人員署名の一致を要求した。

燃料は、戦争に対応する国家計画の評価日に在庫ゼロだった回数を数えた。791 は攻撃213/391・防御212/391、790 は攻撃0/67・防御67/67、792 は攻撃54/106・防御66/106。同じ工業消費を併戦ごとに配分できないため、採取した国単位の需要・実消費は戦争別消費に換算していない。

## 目標と守備の時系列

- 採取した40件の攻守別計画で、同じ開戦に属する目標種別と地区集合は評価間で変わらなかった。最初と最後の評価の間隔は791で60–690日、790で40–390日、792で120–390日。80日以上観測でき、達成フラグと対象地区の法的所有者が通期で変化しなかった攻撃側／防御側は、791で5件／1件、790で0件／0件、792で2件／0件。この指標は目標の進捗停滞の目安であり、戦線全体の停滞期間は別途観測が必要。
- 791 の `nation-3` は3020–3080日に講和と防衛を3回往復した。交戦相手、対象地区、連立、イデオロギー、領土版、首都緊急、燃料枯渇の有無は各転換点で同じだった。軍事方針は防衛を継続。一方、観測した戦力比は1.59–1.81、損耗率は51.92–52.00%で変化しており、同一入力での判断矛盾は確定できない。他の国・シードでこの往復は抽出されなかった。
- 指揮官の発進判断は791で2件、790で1件、792で2件。すべて発進で増援待ちの記録はなかった。5件すべてで同日の国家計画は軍事方針が防衛だった。うち791の5690日には国家の戦略方針が講和だった。発進ゲートを通過した記録と同日の計画の照合であり、判断時点の因果や命令違反は未確定。発進判断のない戦争について、検討の機会がなかった場合と記録に残らなかった場合は区別できない。
- 首都に戦闘力がない日は、脅威下の国・首都別延べ日数で791が1,041/4,607、790が405/1,252、792が371/1,079。このうち首都に陸上部隊がいない日は順に503・239・371。併戦中は同じ首都を一度数え、首都移転後は新しい位置を追った。790の初期戦では攻撃側 `nation-0` に94日の空白があり、空白開始の24日には燃料があった。防御側 `nation-2` は128日戦闘力ゼロだったが、部隊は首都に残っていた。同国は40回の計画評価すべてで燃料ゼロ。792の同じ防御側は211日無人で、燃料は40回の評価すべてでゼロだった。燃料枯渇だけで守備空白を説明できず、担当部隊、組織率、経路や到着可能性の個別照合が必要。

### 講和と防衛の得点

791 の `nation-3` は3020–3080日の各評価で同じ相手への講和と防衛を比較できた。公開済みの成立可能な合意は全評価でゼロ。交戦構成・政体・対象地区に加え、この区間に他国の開戦・終結も記録されなかった。講和と防衛の不確実性・変更費用はともにゼロ。講和の直接費用が防衛より低い一方で、補充不足のペナルティは防衛より高い日があった。表はリスク回避係数を掛けた得点への寄与を示す。

### 攻守別の守備と燃料

戦争が一覧にある日の攻守別集計。脅威は現在の首都に対するエンジンの評価を使い、当日の首都にいる陸上部隊の合計戦闘力がゼロなら守備なしと数えた。燃料は在庫ゼロの日数と、工業の評価が更新された日の燃料維持需要・実支払を集計した。併戦中は同じ国の同じ日と燃料が各戦争に現れるため、表は戦争ごとの観測値の合計で、世界全体の消費量や個別戦争に帰属する消費量には使えない。

| 条件 | 攻撃側の脅威下守備なし／脅威日 | 防御側の脅威下守備なし／脅威日 | 攻撃側の燃料ゼロ日／日数、実支払／需要 | 防御側の燃料ゼロ日／日数、実支払／需要 |
| --- | ---: | ---: | --- | --- |
| 791 | 484 / 2,010 | 925 / 3,647 | 2,122 / 3,893、1,767 / 4,353 | 2,110 / 3,893、36 / 3,847 |
| 790 | 108 / 613 | 297 / 639 | 9 / 668、286 / 1,828 | 668 / 668、0 / 375 |
| 792 | 40 / 499 | 451 / 891 | 540 / 1,047、489 / 1,988 | 665 / 1,047、204 / 1,177 |

- 790初戦の攻撃側は21日に首都の唯一の部隊が予備任務で移動を始め、24日に首都を離れた。在留部隊は移動開始時に戦闘力があり、燃料維持費は初戦全体で184／184を支払った。空白の発生は部隊の転進と一致した。
- 同戦の防御側は戦車が首都に残った。10日に燃料切れのユニット状態へ変わり、戦闘力がゼロになった。初戦を通じ、国の燃料維持需要303に対する支払はゼロ。首都無人は0日で、脅威下の戦闘力ゼロは128日だった。
- 792初戦の防御側は211日の空白がすべて首都無人。初期から周辺戦線に割当があり、首都で最初に記録された陸上部隊は332日にいた歩兵で、燃料停止状態ではなかった。燃料維持需要63への支払はゼロだった。首都への配置・到着の空白と、790で在留戦車が停止した事例を区別できた。

### 指揮官の判断機会と判定

終結18戦・36陣営では、指揮官の判断を記録した陣営が4、作戦は観測したが指揮官の判断段階が記録されなかった陣営が18、該当する作戦を観測しなかった陣営が14。継続中の2戦・4陣営では、観測終了までに1陣営で指揮官の判断があり、3陣営に該当作戦がなかった。5件の判断はいずれも発進時の準備率が指揮官の希望値を満たし、追加集結を待つ条件は成立しなかった。同日の国家軍事方針は全件で防衛。既存の戦線判断は、局所の戦力条件を満たす反撃や継続作戦を防衛方針の下でも許す。

この3シードで、候補得点の反転、予備部隊の転進、在留戦車の燃料停止、首都への部隊未到着をそれぞれ観測した。同じ原因による再現例が揃っていないため、旧守備介入の再試験は保留する。次の比較に進む根拠は、別事例でも戦略方針の反転が繰り返され、実行や帰結に差が出ること。再検討時は補充見積もりを固定する対照と、実際の任務・終結・費用を併せて確認する。
