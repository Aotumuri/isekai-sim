# 工業調達の買い手別診断

[R-002](R-002.md) の計測設計を実装した。`WORLD_PROCUREMENT_FUNNEL=1` を付けると長期世界診断が、世界集計に加えて買い手国・資源別に検討、候補なし、経路なし、配船時拒否、出航、着荷、返還の累計を出力する。出航・着荷・返還は取引 ID と数量を同じ観測から取得する。診断の集計には取引ごとの履歴を保持しない。配船時拒否には既存の `false` が表す複数の条件が含まれる。

Node 24.22.1 で、作業ツリーの計装を有効・無効にして小規模シード109を6,000日まで比較した。両方の世界署名は `44b4f1b0b51e2a6341208b4f426210021173a33d05f048fd53206be3d31c6e44`。観測ありでは買い手・資源の組が28、検討1,254件、候補なし1,137件、経路なし2件、配船時のその他拒否0件、出航115件、着荷114件、返還1件。発注試行の合計117件、出航・着荷・返還と資源別着荷量は既存の世界集計と一致した。配船時拒否は固定の海上取引テストで再現した。この標本は供給源の偏り・候補の除外条件が一般にどの程度効くかを推定するものではない。

```sh
WORLD_SIGNATURE=1 node --expose-gc --import tsx test/diagnostics/long-term-world.ts quick 109 6000
WORLD_PROCUREMENT_FUNNEL=1 WORLD_SIGNATURE=1 node --expose-gc --import tsx test/diagnostics/long-term-world.ts quick 109 6000
```

工業調達の回帰16件、アプリ全体927件、型検査とビルドが成功した。検証は未コミットの作業ツリーで実行した。限定比較のため計装の時間コストは評価していない。
