# プロジェクト内 ADF の設計とロードマップ

## 現行コードから確認した原因

- `.agents/skills` は旧 `agents/tools/research.py` を起動し、Desktop は `adf/sessions.py` と SQLite で別に状態遷移を管理していた。直近の対策は管理スレッドから旧 Skill を隠し、共有ロックで競合を防ぐものだった。
- `adf/store.py` が Application Support を既定にし、`service.py` の登録・権限検査は ADF 自身を含むリポジトリの登録を拒んでいた。監督の DB に関する復旧をエージェントに任せると、公式サンドボックスの境界で止まる。DB の所有は監督に一本化する。
- AppKit が `desktop_bridge.py` 経由で監督に接続していた。画面更新に再ビルドが必要で、結果不明の操作に対する Core の照合をすべて GUI から実行できなかった。
- `.git` は Codex プロファイルで読み取り専用。人間の差分確認とコミットを維持し、監督に Git 書き込みを委譲しない。

## 構成

- 各チェックアウトの `adf/runtime/` に運用 TOML、SQLite、実験、IPC、保全コピーを置く。単一監督とプロジェクト行で既存の主キー・外部キーを保持する。クライアントに登録・切替操作を公開しない。
- CLI、Web、Skill から同じ監督の操作を呼ぶ。Web は数値ループバックの個別ポートで動かし、閉じても監督を終了しない。Codex と GitHub は既存の App Server と gh アダプターを利用する。
- GitHub が課題の正本。SQLite の実行用の課題 ID と照合情報は GitHub の Issue に結び付ける。実験待機、利用枠確認、停止世代の検査はプログラムが処理する。
- 通常の Codex スレッドでの Skill 利用は読み取り・相談と、人間への管理セッション起動手順の提示に限る。公開 RPC は管理下の保存済みスレッドを ID で再開できる。外部クライアントの実行中スレッドの所有権や起床は保証できない。 [公式 App Server](https://learn.chatgpt.com/docs/app-server)
- 管理ロールの公式プロファイルで ADF 本体と運用状態への書き込みを拒否し、運用状態の読み取りも拒否する。Web とファイル IPC は OS ユーザーを信頼する。外部スレッドには同じプロファイルを強制できない。

## 段階と判定

| 段階 | 優先する変更と判定 |
| --- | --- |
| A | ローカル監督、統一 CLI・Skill、停止と世代管理、旧状態のプレビュー・保全・選択取り込み。隔離テストで二つのチェックアウトが同時に動き、クラッシュ後の再開と実験通知の重複防止を確認する。 |
| B | ビルド不要の Web、会話・停止・承認・結果照合、Mission/範囲、運用モード。模擬 Codex と GitHub で全経路を確認し、公式認証・制限と権限境界を実環境で確認してから研究運用へ移る。 |
| C | Program と研究品質（分類別報告、否定的結果、独立レビュー）、内部メッセージと起床条件、研究報告の全文検索、任意の意味検索、時間帯・予算配分、スレッド方針、権限付き Worker/Reviewer。既存履歴を保ち、重複起床と複数書き手を抑え、外部 API は明示承認後のみ利用する。 |
| D | 対話導入、既定の Snapshot に加えて Working Tree・Worktree 実験、資源上限、保持ポリシー、ホスト枠、他 OS、更新元と署名・自動更新・復元。停止中の整合性検査と復元試験が通り、重要成果物の保全を確認してから有効にする。 |

C・D は既存機構を維持しながら段階導入する。研究課題の生成には Mission、既存・失敗課題の照合、起票と着手の独立した承認が必要。Research Autonomous の受け入れでは有意義な候補のない場合の停止、既存課題の選択と次の仮説への継続を別々に確認する。

## 今回導入した運用と次の受け入れ条件

| 仕様 | 現在 | 次の実装と受け入れ条件 |
| --- | --- | --- |
| 導入・停止・復旧 | チェックアウトに束縛した単一監督、起動世代、CLI・Skill・Web、穏やかな停止と即時停止。旧 AppKit の配布経路を廃止。 | 外部 Codex スレッドの自動制御は公式の所有権と通知が利用できる場合に再検討する。Core が認可できるスレッドだけを対象とし、重複起床・停止後の起床を回帰で検証する。 |
| 状態の移行 | Desktop は一致するプロジェクトの保存情報を選択して取り込み、旧 CLI は参照用アーカイブに保存する。移行元停止、排他、指紋、競合、整合性を確認する。 | 旧スキーマの状態をさらに引き継ぐには、所有権・ジョブ・承認の変換を明示する。失効した起床を再生せず、同じ旧状態を二回移行して差分がないことを検証する。 |
| 研究と課題の承認 | Mission と実行範囲、GitHub 優先度・依存・進捗、四モード、独立した起票と着手承認、限定的な探索。 | C で Program、AI／混合選択、Coordinator 確認、事前ラベル等による着手を追加する。依存と権限をプログラムで絞った候補だけを評価させ、未承認課題・重複・失敗知見の反復を防ぐ。生成後の着手と次の探索を無人で連鎖させる運用はこの判定の後に有効化する。 |
| ロールと通信 | 基本ロールを分け、追加ロールのモデル・推論・指示・予算・回復方式を設定できる。GitHub を共通の記録に使用する。 | C で起床条件、内部メッセージ、レビューと Worker を追加する。役割間の独立性、再委任禁止、書き手一人、通知のみで推論が始まらないことを検証する。共有ロックは必要なホスト制限だけに使う。 |
| 研究品質と記憶 | GitHub と既存 Markdown を永続資料にし、探索時は否定的な結果も参照する。 | C で分類別の報告、独立レビュー、全文検索、知見と未解決問題の整理を追加する。履歴から同じ失敗を検索できること、単純な修正に研究書式を要求しないことを確認する。意味検索は費用と外部送信の明示承認に依存する。 |
| 実験、予算、会話 | Snapshot、実行条件、成果物、待機中の追加推論抑制、同一スレッドへの再開、公式利用枠確認後の再開を維持する。 | C・D で課題単位のスレッド選択、時間帯・利用枠の配分、および Working Tree・Worktree アダプターを追加する。既定 Snapshot と実験入力・実行制限を分離し、並行・中断・再現性を比較してから採用する。 |
| Git と外部操作 | GitHub の操作別ポリシーと結果の照合。Git メタデータは公式プロファイルで読み取り専用。 | Git 書き込みの自動化は公式の操作単位承認と権限縮小を強制できる方式に依存する。承認された変更だけをコミットし、拒否時に Core を介して権限が広がらないことを検証する。 |
| 保守 | 停止中の整合性検査とバックアップ、手動更新。運用データを Git から除外する。 | D で明示した更新元、改変検証、スキーマ・依存更新、復元、保持期間・容量、対話導入、他 OS 対応を追加する。更新失敗の中断試験と復元試験を通し、重要な証拠は保持する。 |

管理モードの既定は安全側に保つ。現行の Research Autonomous は一回の範囲承認から探索までの基本版。予算・権限の根拠を持たない連続探索は起動しない。実ユーザーデータの切替と実 Issue の書き込みは、運用者が承認した範囲で別途確認する。

## 受け入れ結果

- **隔離した模擬試験**では ADF 49 件、旧 CLI 24 件が通過した。二つのチェックアウトでの独立起動、監督の強制終了と再起動、旧 IPC 世代の拒否、承認の失効、移行中断からの続行、バックアップ後の状態保持を確認した。
- **実ブラウザ・模擬サービス**では Chrome で複数行の会話、Markdown とコード、未信頼 HTML の無害化、Host・Origin・認証、承認待ちでの停止、送信結果不明の照合、画面を閉じた間の実験継続を確認した。待機中のターン要求増分と観測トークン増分は各 0。同じスレッドへの再開は一回だった。
- **公式サービス**では App Server の ChatGPT 認証と利用枠の取得、合成ファイルでの ADF 本体・運用状態の権限境界、GitHub Issue #28 一件の読み取りを確認した。推論ターン、実 GitHub の更新、実データ移行は未実施。
- `adf/runtime/` と `agents/runtime/` に追跡ファイルはない。旧 `agents/research/state.json` と inbox にある追跡ファイルは完了済み研究の履歴として残す。

再現手順は次のとおり。Chrome 試験は使い捨てのプロファイルとローカル HTTP を使用する。公式 App Server の確認はユーザーの通常環境で実行する。

```sh
python3 -m unittest discover -s tests/adf
python3 -m unittest discover -s agents/tools/tests
node tests/adf/web_e2e.mjs
PYTHONPATH=. python3 tests/adf/live_acceptance.py
```
