# ADF Desktop の独立 UI/UX レビュー

2026 年 11 月 26 日、Apple Silicon の macOS 15.7.1 で実施。改善前は `4a65b09` からビルドした。試験版はバンドル識別子、状態領域、App Server の接続先を隔離し、使い捨て Git リポジトリを登録した。AppKit、SQLite、IPC、スナップショット、実験の Python 計算は実際に動作させた。模擬 App Server が推論応答と利用枠を返したため、公式の推論枠を消費せずに試験できた。実 GitHub は利用していない。

## 優先度と対応

| 優先度 | 観測と影響 | 対応 |
| --- | --- | --- |
| P0 | 改修途中の実機試験で、研究と実験タブにテキストが存在しても、スクロール領域が描画されないケースがあった。結果確認ができない。 | タブの余白とスクロール領域の寸法を明示し、最終コードの GUI で研究、ログ、成果物を再表示して確認した。 |
| P0 | ソース確認で、操作ポリシー欄の入力が `=` のみの場合、空配列の先頭参照でクラッシュし得ることを確認した。 | 操作別の三択に置き換え、自由入力の解析を廃止した。 |
| P1 | 初回の会話タブが右に寄り、左半分が余白だった。未登録でも開始・停止が有効で、何を始めるべきか判断しづらかった。 | 会話領域を全幅で表示し、登録案内を追加。プロジェクトやロールの状態で操作を有効化する。 |
| P1 | 登録エラー後に正しいフォルダを登録しても、エラーが画面下に残った。停止後の次の操作も履歴を探す必要があった。 | 登録・送信・設定保存・停止・再開に受付結果を表示。両ロールの状態、現在の研究、停止理由、次の操作、研究予算と取得済み利用枠を全タブの上部で確認できる。 |
| P1 | 運用モード、ランタイム、依存課題、承認する課題の選択に綴りや ID が必要だった。 | プルダウンとチェックボックスを使用。GitHub は最近のオープン Issue と一覧外番号を併用できる。モデル候補と対応する推論強度は App Server から取得する。 |
| P2 | ログを開く対象が選択済みでも本文が空のことがあり、状態変更時に選択が移る可能性があった。成果物にはファイル名の再入力が必要だった。 | 実験 ID で選択を維持し、タブ表示時に取得する。ログへ戻る操作と成果物の候補選択を追加した。 |
| P2 | 入力欄がすべて単行で、課題の条件や研究方針が読みづらい。即時停止はクリック一回で実行された。 | 課題条件・範囲・追加指示を複数行にし、即時停止に確認を追加した。 |
| P2 | 手動ビルドは Python の場所を要求し、従来のバンドルは厳密な署名検査に失敗した。更新時の停止と保全を利用者が判断する必要がある。 | ローカルビルド時にアドホック署名を検証。バージョン別の出力先、旧監督の停止、状態のバックアップ、更新確認を README に記載した。 |
| P3 | 初回導入には Python、開発ツール、Codex CLI のセットアップが必要。履歴・トークン詳細や GitHub の下書きには JSON が残る。 | 署名・公証済み配布は配布主体と更新方式が決まった段階で検討。詳細履歴の検索、構造化表示、フォーム内のエラー保持は今後の改善候補。 |

AppKit のタブ、フォルダ選択、プルダウンは macOS の標準操作に沿う。改善後は 19 pt の概要見出しと 13 pt の本文で現在地と詳細を区別できる。ライトでは白い読み取り面、ダークでは暗色の読み取り面と明るい文字を確認した。最小サイズの 780 × 544 pt 付近でも主要操作と研究内容を表示できた。長文は会話欄で折り返してスクロールできた。複数の停止理由や長い名称が重なる場合の表示、最大サイズのログと VoiceOver は要追加検証。

## 操作ガイド

1. 「プロジェクトを登録」で Git 作業フォルダを選ぶ。ローカル課題を使う場合は GitHub 欄を空欄にする。「ロール設定」で対象ロールとモデルを選ぶ。
2. 「エージェント」で Coordinator に方針を相談する。「研究」で課題名と完了条件、必要なら先に完了すべき課題を登録する。
3. 「運用プリセット」でモードと上限を保存する。「承認範囲で開始」で課題、制約、実験条件を確認して開始する。上部の「利用枠を取得」で公式使用率を確認し、研究予算はその上の観測トークン表示で確認する。
4. 「実験」でログと成果物、「履歴と利用量」でターン数とトークン内訳を見る。停止や承認待ちは上部の案内に従う。画面だけを閉じる場合は「バックグラウンドで継続」を選ぶ。
5. 新規導入と安全な更新は [README](README.md#インストールと起動) を参照。
